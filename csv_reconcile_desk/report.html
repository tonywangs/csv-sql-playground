CSV Reconcile Desk / Offline report

Every record accounted for.

Inspect definite differences. Keep ambiguous matches unresolved.

Schema and comparison rules

Values are compared as exact strings. No trimming, numeric conversion or fuzzy matching. An empty key component is unresolved. Exact duplicate records cancel one-for-one in source order; these are multiset matches, not proof of individual identity. Remaining records on both sides of a duplicate key stay unresolved. A changed pair requires a key unique in both inputs. Absent columns differ from empty cells.

    Unresolved records need your judgment. The report makes no pairing or change claim for these records.
    Rows are 1-based data-record numbers, excluding the header. Lines are 1-based physical file lines, including the header. Each record appears exactly once per source. This self-contained report uses no external scripts, fonts or network requests. Share it only with people who may see the source data.
